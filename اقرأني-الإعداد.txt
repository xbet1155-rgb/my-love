حكايتنا — النسخة المربوطة (الأدمن بيحدّث الموقع تلقائي)

الملفات:
  index.html   الموقع اللي حبيبك بتفتحه
  admin.html   لوحة التحكم بتاعتك
  config.js    بيانات الربط (هتعدّله مرة واحدة)
  setup.sql    إعداد قاعدة البيانات (هتشغّله مرة واحدة)
  style.css, common.js  ملفات مساعدة، مش لازم تلمسها

الإعداد (حوالي 10 دقايق، ببلاش ومن غير كارت):

1) ادخل supabase.com واعمل حساب، وبعدين New project (اختار أي اسم وكلمة سر لقاعدة البيانات).

2) من القائمة: Authentication ← Users ← Add user ← Create new user
   - الحساب الأول (الأدمن):  الإيميل admin@hekayetna.app + كلمة سر قوية بتاعتك
   - الحساب التاني (الزائر):  الإيميل viewer@hekayetna.app + كلمة سر الموقع اللي هتديها لحبيبك
   فعّل خيار Auto Confirm User في الاتنين.

3) من القائمة: SQL Editor ← New query ← الصق محتوى ملف setup.sql كله ← Run.
   لازم تشوف Success.

4) من القائمة: Project Settings ← API
   انسخ Project URL و anon public key وحطهم في ملف config.js مكان PUT_YOUR...

5) افتح admin.html في المتصفح، ادخل بإيميل وكلمة سر الأدمن، وضيف صور ورسائل.
   افتح index.html (أو زرار 👁 الموقع) وادخل بكلمة سر الزائر.
   أي إضافة أو تعديل أو حذف من الأدمن بيظهر في الموقع لوحده، من غير ريفريش.

النشر (عشان حبيبك تفتح الموقع من لينك):
   ارفع الفولدر كله على Netlify Drop (app.netlify.com/drop) أو GitHub Pages، وابعتلها اللينك.
   ملاحظة: خلّي admin.html معاك بس لو عايز، أو ارفعه عادي — محدّش يقدر يعدّل من غير حساب الأدمن.

ملاحظات:
  - الرسائل المقفولة بتتقفل من السيرفر: نص الرسالة مش بيوصل لجهاز الزائر إلا لما وقتها يجي.
  - لو غيّرت إيميل الأدمن، غيّره في setup.sql وفي config.js.
  - الباقة المجانية: 1 جيجا تخزين وأقصى حجم للملف 50 ميجا. كفاية جداً لموقع زي ده.
